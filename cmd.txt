CAREER HUB - HOW TO RUN
=======================================================================

QUICK START (this is all you normally need)
-----------------------------------------------------------------------
Open PowerShell, then paste these two lines:

    cd "C:\Users\user\Desktop\Master folder for work\career-hub"
    python -m uvicorn main:app --port 8020

Then open this in your browser:

    http://localhost:8020

To stop the server: press Ctrl+C in that PowerShell window.


IMPORTANT - USE "python -m uvicorn", NOT "uvicorn"
-----------------------------------------------------------------------
On this machine uvicorn is installed but is NOT on the PATH, so typing

    uvicorn main:app --port 8020            <-- does NOT work here

gives "uvicorn : The term 'uvicorn' is not recognized".
Always use the "python -m uvicorn ..." form above.


FIRST TIME ONLY - INSTALL DEPENDENCIES
-----------------------------------------------------------------------
Already installed on this machine (fastapi 0.115.5, uvicorn 0.32.1,
pydantic 2.12.5 on Python 3.12.5 at C:\Python312\python.exe), so you can
skip this. Needed only on a fresh machine, or if you see
"No module named 'fastapi'":

    cd "C:\Users\user\Desktop\Master folder for work\career-hub"
    python -m pip install -r requirements.txt


IF THE PORT IS ALREADY IN USE
-----------------------------------------------------------------------
Symptom: "[Errno 10048] error while attempting to bind on address
('127.0.0.1', 8020)" - a copy is already running.

Either just open http://localhost:8020 (it's already up), or use a
different port:

    python -m uvicorn main:app --port 8030

Or find and stop whatever holds the port (PowerShell):

    Get-NetTCPConnection -LocalPort 8020 -State Listen |
        Select-Object -ExpandProperty OwningProcess |
        ForEach-Object { Stop-Process -Id $_ -Force }


AFTER EDITING THE RESEARCH DOCUMENTS
-----------------------------------------------------------------------
The hub does not read the source files live - it reads a built copy.
If you edit any of these:

    ..\Freelancing\ai-income-playbook.html
    ..\Job search\US remote jobs\us-remote-ai-jobs-guide.html
    ..\Job search\ai-target-companies-and-outreach-strategy.html
    ..\Job search\gcc jds\*.md
    ..\Job search\websites for remote work.txt

then rebuild, and refresh the browser:

    cd "C:\Users\user\Desktop\Master folder for work\career-hub"
    python build_content.py

The build prints every section with its size. It stops with an error
instead of producing a half-empty page if a source document's layout
has changed.

You do NOT need to restart the server after a rebuild - only refresh
the page (Ctrl+F5 if it looks stale).


DEVELOPING (only if you are changing the app's own code)
-----------------------------------------------------------------------
Add --reload so the server restarts when main.py changes:

    python -m uvicorn main:app --reload --port 8020

Note: --reload does not watch static/ - for changes to
static/app.js, static/style.css or static/index.html just refresh the
browser with Ctrl+F5.


YOUR SAVED DATA
-----------------------------------------------------------------------
Anything you mark with "+ track" (status + notes) is saved to:

    career-hub\state.json

That is the only file worth backing up - everything else can be
regenerated by build_content.py. To use the hub on the laptop as well,
copy the whole career-hub folder including state.json; there is no sync
between machines.


KEYBOARD SHORTCUTS (in the browser)
-----------------------------------------------------------------------
    /            focus the search box
    Esc          close the status popover / search results
    Ctrl+Enter   save the note you are typing


TROUBLESHOOTING
-----------------------------------------------------------------------
"python is not recognized"
    Use the launcher instead:  py -m uvicorn main:app --port 8020

"No module named 'main'"
    You are in the wrong folder. cd into career-hub first (the folder
    holding main.py), then run the command again.

Page loads but is empty / no sections
    static\content.json is missing or stale. Run: python build_content.py

Browser shows an old version after a rebuild
    Hard-refresh with Ctrl+F5.
